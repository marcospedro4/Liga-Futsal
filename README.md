🏆 API Liga Futsal
API RESTful para gerenciamento de liga de futsal, incluindo times, jogadores e árbitros.
📝 Descrição do Projeto
Sistema desenvolvido para gerenciar uma liga de futsal completa, permitindo cadastro e controle de:

Times: Registro de equipes com informações sobre cidade e técnico
Jogadores: Cadastro de atletas vinculados aos times
Árbitros: Controle de árbitros credenciados na liga

🚀 Tecnologias Utilizadas

Java 17
Spring Boot 3.2.x
Spring Data JPA
MySQL 8.0
Maven
Lombok
Validation API
Spring Web
✅ Validações Implementadas

Times: Nome, cidade e técnico são obrigatórios
Jogadores: Nome, data de nascimento, posição e número da camisa são obrigatórios
Árbitros: CPF e registro de federação devem ser únicos

🧪 Testando a API
Use o Postman ou Insomnia com os exemplos de requisições fornecidos acima.
